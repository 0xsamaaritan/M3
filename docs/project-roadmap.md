## Proposed (not yet approved)

### Phase 4.5 — Password Security Best Practices

A structured module on creating and maintaining secure
authentication practices.

### Phase 5 — User Experience and Accessibility

Mobile responsiveness, navigation, keyboard navigation,
screen-reader support (for example announcing results with
`aria-live`), visual consistency and content clarity.

### Phase 6 — Open-Source Readiness

README, LICENSE, CONTRIBUTING.md, security policy, privacy
documentation, issue templates, testing documentation and GitHub
repository presentation.

## Principles that apply to every phase

- Never collect, store or transmit real passwords.
- Use only predefined fictional examples.
- Clearly separate memorability from unpredictability.
- Promote unique passwords, password managers, MFA and passkeys.
