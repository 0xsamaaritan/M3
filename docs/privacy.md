# M3 Privacy Policy

Applies to M3 up to Phase 4.4 (Mnemonic Learning Engine, Password
Predictability Awareness Engine, Security Learning Dashboard and the
Spot the Risk practice module).

## Data Collection

M3 does not collect any personal information, account credentials,
or private memory phrases.

The interactive features contain **no text inputs or forms**. Users
can only choose from predefined fictional examples:

- **Mnemonic Learning Engine** — three fictional sample phrases.
- **Password Predictability Awareness Engine** — four predefined
  educational scenarios.
- **Security Learning Dashboard** — seven topic cards to open and
  close. The "topics explored" counter is kept in memory only and
  resets when the page is refreshed or closed.
- **Spot the Risk** — five fictional scenarios answered by clicking
  predefined buttons. Answers and the score are kept in memory only
  and reset when the page is refreshed or closed.

## Data Storage

M3 does not store anything. It does not use cookies,
`localStorage`, `sessionStorage` or any other browser storage, and
there is no server or database. Results exist only on the page and
disappear when the page is refreshed or closed.

## External Services

M3 runs entirely in the browser. It makes no external API calls and
loads no third-party scripts, fonts, analytics or tracking services.

## Privacy Commitment

Every new feature must be reviewed to ensure that personal and
authentication information is not collected, stored or exposed.
Users are reminded on every interactive feature never to enter real
passwords or private phrases into educational tools.
