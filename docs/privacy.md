
# M3 Privacy Policy

## Data Collection

M3 Version 0.1 does not require personal
information, account credentials, or private
memory phrases.

## Data Storage

The initial version does not store user
passwords or private phrases.

## External Services

The application is designed to operate
without external APIs or third-party
data processing.

## Privacy Commitment

Future features will be reviewed to ensure
that personal and authentication information
is not unnecessarily collected or exposed.
