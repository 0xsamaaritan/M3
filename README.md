# M3

**Memorable. Meaningful. Mindful.**

M3 is an open-source cybersecurity education project focused on password memorability and secure password practices.

## Project Goal

Explore how meaningful memories and mnemonic techniques can help users understand password memorability without encouraging predictable or reused passwords.

## Features

- **Mnemonic Learning Engine** — see how a fictional sentence becomes a first-letter mnemonic, and why memorability alone is not security.
- **Password Predictability Awareness Engine** — learn why familiar phrases, predictable additions, common substitutions and password reuse are risky.
- **Best Practices** — unique passwords, password managers, multi-factor authentication and passkeys.

## Core Principles

- Memorability should not compromise security.
- Every account should use a unique password.
- Password managers should be encouraged.
- Real passwords and private phrases must never be collected.
- Security guidance must be accurate and practical.
