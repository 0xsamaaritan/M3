01 Memorability vs. unpredictability

Key idea

Being easy for you to remember and being hard for others to guess are two different things. Password-guessing tools try popular phrases and familiar patterns first.

Myth: If I can remember it easily, it is a good password.

Fact: A good password must be unpredictable. Memorability only helps once that is true.

ONE ACTION

For the few passwords you must memorize, use several randomly chosen words instead of a famous quote or lyric.

02 Password length

Key idea

Every extra character multiplies the number of guesses an attacker needs. Current NIST guidance (SP 800-63B) recommends at least 15 characters when a password is used on its own.

Myth: A short password full of symbols beats a long one.

Fact: Length usually adds far more protection than a few extra symbols.

ONE ACTION

Aim for at least 15 characters, and let a password manager generate them randomly.

03 Password uniqueness

Key idea

Data breaches happen. Attackers try leaked username and password pairs on many other sites, an attack called credential stuffing. A unique password keeps a breach limited to one account.

Myth: Reusing one very strong password is fine.

Fact: Once a password leaks, its strength no longer matters. Reuse lets one breach unlock many accounts.

ONE ACTION

Start with your email account. It can reset most of your other accounts, so it deserves a password used nowhere else.

04 Password managers

Key idea

A password manager generates long, random, unique passwords, stores them encrypted, and fills them in for you. You only need to remember one strong master password.

Myth: Keeping all passwords in one place is riskier than memorizing them.

Fact: For most people, a reputable manager protected by a strong master password and MFA is far safer than reused or predictable passwords.

ONE ACTION

Choose a reputable password manager and protect it with a long, unique master password and multi-factor authentication.

05 Multi-factor authentication (MFA)

Key idea

MFA adds a second proof, such as a phone app or security key, so a stolen password alone is not enough. Methods differ: security keys and passkeys are strongest, authenticator apps are good, and SMS codes are better than nothing but can be intercepted.

Myth: With MFA turned on, my account cannot be broken into.

Fact: MFA greatly reduces risk, but codes can still be phished. Never share a code and reject sign-in prompts you did not start.

ONE ACTION

Turn on MFA for your email, banking and password manager first. Prefer an authenticator app or security key over SMS.

06 Passkeys

Key idea

A passkey replaces a password with a cryptographic key stored on your device or in your password manager. It only works on the real website it was created for, so a fake phishing site cannot capture it.

Myth: Passkeys send my fingerprint or face to the website.

Fact: Your fingerprint, face or PIN only unlocks the passkey on your device. The website never receives it.

ONE ACTION

When an account offers passkeys, set one up, and make sure you still have a way to recover the account.

07 Common misconceptions

Key idea

Some widely repeated password advice is outdated. Attacks are also largely automated, so every account is a potential target, not only important people's accounts.

Myth: I should change all my passwords every few months.

Fact: NIST no longer recommends routine forced changes. Change a password when there is a sign it has been exposed.

ONE ACTION

When a service reports a breach, change that password straight away, along with any account where it was reused.

Memorability is not enough

A memorable password must also be unique and difficult to guess.

Unique passwords
